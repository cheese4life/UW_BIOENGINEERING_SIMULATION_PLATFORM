Device AxisDevice.UserDefinedProfile

An interface for performing User Defined Profile (UDP) moves and updating the associated user defined profile data.

Functions

MoveRelativeUDP Move axis using the currently selected time-based UDP profile.
UpdateProfileData Update a single position at the specified index in the currently selected user defined profile.
SelectSineWaveMoveProfile Select the sine wave UDP profile and setup to be ready for a relative UDP move.

Fields

CurrentDataStreamIndex Get the current data stream index being used by the motion controller to calculate the target position of the axis during a UDP move.


Functions

MoveRelativeUDP (repeats)
Move axis using the currently selected time-based UDP profile. A time-based UDP profile must have first been selected by calling SelectMoveProfile(). If a time-based UDP profile is not active, this method will return an error.

Async:

    This function call is asynchronous and must be followed up with a call to Wait.

Parameters:

  • repeats unsigned The number of repetitions of the move to perform.

Usage:

    -- Perform user defined move 5 times
XAxis.UserDefinedProfile.MoveRelativeUDP(5)
XAxis.Wait()
UpdateProfileData (index, position)
Update a single position at the specified index in the currently selected user defined profile.

Async:

    This function call is asynchronous and must be followed up with a call to Wait.

Parameters:

  • index unsigned 
       Zero-based index into the profile data array.
  • position number 
    The new position in selected units (mm, um, or nm) to write to this index in the profile data array.

Usage:

    XAxis.UserDefinedProfile.UpdateProfileData(2, 5.5)
XAxis.Wait()
SelectSineWaveMoveProfile (frequencyHz, amplitude, angularAcceleration)
Select the sine wave UDP profile and setup to be ready for a relative UDP move. Note that setting a parameter too high can cause a device error.

Async:

    This function call is asynchronous and must be followed up with a call to Wait.

Parameters:

  • frequencyHz number The frequency of the sine wave in Hz.
  • amplitude number 
     The amplitude of the sine wave in selected units (mm, um, or nm).
  • angularAcceleration number The angular acceleration in Hz per sec.

Usage:

    XAxis.UserDefinedProfile.SelectSineWaveMoveProfile(2.0, 5, 1000)
XAxis.Wait()

Fields

CurrentDataStreamIndex
Get the current data stream index being used by the motion controller to calculate the target position of the axis during a UDP move.
  • CurrentDataStreamIndex unsigned readonly

Usage:

    local currentDataStreamIndex = XAxis.UserDefinedProfile.CurrentDataStreamIndex

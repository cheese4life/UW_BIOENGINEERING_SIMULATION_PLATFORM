Functions

Connect ()
Establish a connection to the device.
Initialize ()

Initialize the device and makes it ready for use.

This function does not need a Wait call after it - this function blocks until the device is initialized.

In the case of an axis this involves:

  • Establishing a connection to the hardware.
  • Performing Analog Calibration.
  • Performing Commutation.
Wait ([timeout_ms=DefaultTimeout_ms])
Wait for the previous asynchronous action on this device to complete.

Each device can have only one action in progress at a time - starting another action while one is already in progress raises an error. Wait waits for the currently-running action to finish before returning, or checks the last action's status if it has already completed. After Wait returns, another action can be started.

Changes to device settings are also asynchronous, and require Wait to be called to block until the setting has actually been set.

Parameters:

  • timeout_ms int The length of time to wait from when this function is called before raising a timeout error. (default DefaultTimeout_ms)

Raises:

An error is raised if the timeout expires before the action completes, the previous asynchronous action was EStopped or if the action or setting change being waited on fails for any other reason.

Usage:

    Device.PerformAction()

-- The function above returns immediately, but the action is still in progress.
-- We can call Wait() to block until the action is actually finished.
Device.Wait()
Shutdown ()
Shutdown the device in preparation for power off. Once a device has been shutdown, it will accept no further commands. If there is a connection associated with this device and this is the last device using the connection, the connection will be closed.

Async:

    This function call is asynchronous and must be followed up with a call to Wait.

Usage:

    Device.Shutdown()
Device.Wait()
EStop ()
Perform an emergency stop of the device. This will immediately halt any motion (e.g. an abrupt stop will be performed for an axis device) and return the device to a safe, passive state (e.g. for an axis device this means the operating mode is set to disable the axis, motor output, current control, position loop, and trajectory). The next call to Wait() on this device will raise an error, indicating the device has been EStopped and the command in progress was interrupted. Alternatively, EStopWait() can be called to wait for the estop to complete without throwing an exception. Initialize() must be called on this device before it will accept further commands.

Async:

    This function call is asynchronous and must be followed up with a call to EStopWait.

See also:

    EStopWait

Usage:

    Device.EStop()
Device.EStopWait()
EStopWait ([timeout_ms=DefaultTimeout_ms])
Wait for the previous EStop to complete. Does not raise an error if the EStop was successful.

Parameters:

  • timeout_ms int The length of time to wait before raising a timeout error. (default DefaultTimeout_ms)

Raises:

An error is raised if the timeout expires before the EStop completes.

See also:

    EStop

Usage:

    Device.EStop()

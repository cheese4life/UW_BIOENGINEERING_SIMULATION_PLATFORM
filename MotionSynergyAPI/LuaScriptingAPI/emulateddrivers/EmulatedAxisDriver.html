SetResponse (response)
Set the driver response to be returned for all subsequent actions.

This provides a simple mechanism for injecting errors. Note that this function will also clear the current response list if present.

Parameters:

  • response string

    The driver response code can be one of the following strings:

    • 'DriverSuccess'
    • 'DriverCommunicationFailure'
    • 'DriverGeneralError'
    • 'DriverBusy'
    • 'DriverInvalidState'
    • 'DriverUnableToGetOrSetValue'
    • 'DriverActionFailed'
    • 'DriverHalt'
    • 'DriverEStop'

Usage:

    -- set a device driver to return DriverActionFailed when an action is called
EmulatedDriver.SetResponse('DriverActionFailed')

-- attempting to call the device function will raise a DriverActionFailed error
Device.PerformAction()
Device.Wait()
AddToResponseList (response, count)
Set the response code to be returned for the next 'count' actions.

This provides a simple mechanism for specifying a sequence of responses. Can be called multiple times to build up a varying sequence of responses. Note that once all responses have been used, the fixed response code specified by SetResponse will be used.

Parameters:

  • response string See response parameter in SetResponse.
  • count int The number of actions to return the response code for.

See also:

    SetResponse

Usage:

    -- set driver to complete the first 2 actions successfully
EmulatedDriver.AddToResponseList('DriverSuccess', 2)
-- then raise a general error on the third action
EmulatedDriver.AddToResponseList('DriverGeneralError', 1)

-- the first 2 device actions will run without errors
Device.PerformAction()
Device.Wait()
Device.PerformAction()
Device.Wait()
-- this third action will raise a DriverGeneralError
Device.PerformAction()
Device.Wait()
SetCurrentPosition (position)
Set the emulated axis motor position.

This function updates the CommandedPosition and ActualPosition axis fields to the specified value.

Parameters:

  • position int The new axis position.

Usage:

    -- set the internal position value to 123
EmulatedAxisDriver.SetCurrentPosition(123)

-- the emulated axis device will now return 123 as its position
local position = Axis.CommandedPosition
SetFlagStatusEnable (flagIndex, enable)

Sets the enable status of the emulated flag range.

The flag status is enabled by default and the flag status changes when the axis is within the flag range. When disabled, the flag status returned within the range is always zero.

Example instrument configuration snippet for setting up emulated flags:

[Axis_Device]
Type=AxisDevice
Driver=EmulatedAxisDriver
NamedFlags=Axis_NamedFlags

# name the flag at index 0 as 'Flag1' and flag at index 1 as 'Flag2'
[Axis_NamedFlags]
Flag1=0
Flag2=1

[EmulatedAxisDriver]
Type=EmulatedAxisDriver
NamedFlagPositions=EmulatedAxisDriver_NamedFlagPositions
NamedFlagExtents=EmulatedAxisDriver_NamedFlagExtents

# set up 'Flag1' (index = 0) flag range between 0 and 100
# set up 'Flag2' (index = 1) flag range between 100 and 5100
[EmulatedAxisDriver_NamedFlagPositions]
0=0
1=5000

[EmulatedAxisDriver_NamedFlagExtents]
0=100
1=5100

Parameters:

  • flagIndex int The flag index to set the enable status for.
  • enable bool The enable status to set.

Usage:

    -- In this example, we are using flag range specified in the
-- axis configuration from the example above.

-- move the axis to position 5000 which is within the Flag2 range
Axis.MoveAbsolute(5000)
Axis.Wait()

local flag1 = Axis.GetFlagStatus('Flag1') -- returns false
local flag2 = Axis.GetFlagStatus('Flag2') -- returns true

-- now disable the enable status on Flag2 (index = 1)
EmulatedAxisDriver.SetFlagStatusEnable(1, false)

-- Flag2 status now reports false even though it is within range
flag2 = Axis.GetFlagStatus('Flag2') -- returns false

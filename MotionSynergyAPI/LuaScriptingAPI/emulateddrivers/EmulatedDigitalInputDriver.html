SetResponse (response)
Set the driver response to be returned for all subsequent actions.

This provides a simple mechanism for injecting errors. Note that this function will also clear the current response list if present.

Parameters:

  • response string

    The driver response code can be one of the following strings:

    • 'DriverSuccess'
    • 'DriverCommunicationFailure'
    • 'DriverGeneralError'
    • 'DriverBusy'
    • 'DriverInvalidState'
    • 'DriverUnableToGetOrSetValue'
    • 'DriverActionFailed'
    • 'DriverHalt'
    • 'DriverEStop'

Usage:

    -- set a device driver to return DriverActionFailed when an action is called
EmulatedDriver.SetResponse('DriverActionFailed')

-- attempting to call the device function will raise a DriverActionFailed error
Device.PerformAction()
Device.Wait()
AddToResponseList (response, count)
Set the response code to be returned for the next 'count' actions.

This provides a simple mechanism for specifying a sequence of responses. Can be called multiple times to build up a varying sequence of responses. Note that once all responses have been used, the fixed response code specified by SetResponse will be used.

Parameters:

  • response string See response parameter in SetResponse.
  • count int The number of actions to return the response code for.

See also:

    SetResponse

Usage:

    -- set driver to complete the first 2 actions successfully
EmulatedDriver.AddToResponseList('DriverSuccess', 2)
-- then raise a general error on the third action
EmulatedDriver.AddToResponseList('DriverGeneralError', 1)

-- the first 2 device actions will run without errors
Device.PerformAction()
Device.Wait()
Device.PerformAction()
Device.Wait()
-- this third action will raise a DriverGeneralError
Device.PerformAction()
Device.Wait()
SetInputBitState (bitIndex, state)
Set the state of the bit addressed by the bit index.

Parameters:

  • bitIndex int or string The index as an integer from 0 to 7, or string from 'ZERO' to 'SEVEN'.
  • state bool True to set to 1, false to set to 0.

Usage:

    -- set bit 1 to 0 (LOW)
EmulatedDigitalInputDriver.SetInputBitState(1, false)
-- set bit 5 to 1 (HIGH)
EmulatedDigitalInputDriver.SetInputBitState('FIVE', true)

local bit1 = DigitalInput.Input1 -- returns 0
local bit5 = DigitalInput.Input5 -- returns 1
AddToInputBitStateList (bitIndex, state)
Add to a list of input bit changes for the emulated driver to perform before each read.

Note that items in the bit state list are processed on any read performed on the device interface, which includes any application code that calls read from this device outside of the Lua script environment.

Parameters:

  • bitIndex int or string The index as an integer from 0 to 7, or string from 'ZERO' to 'SEVEN'.
  • state bool True to set to 1, false to set to 0.

Usage:

    -- set up a bit state change list on bit 2
EmulatedDigitalInputDriver.AddToInputBitStateList(2, true) -- return 1 on first read
EmulatedDigitalInputDriver.AddToInputBitStateList(2, false) -- return 0 on second read
EmulatedDigitalInputDriver.AddToInputBitStateList(2, true) -- return 1 on third read

local bit2 = DigitalInput.Input2 -- returns 1
bit2 = DigitalInput.Input2 -- returns 0
bit2 = DigitalInput.Input2 -- returns 1

ResponseListLooping
Specifies whether a response is discarded from the response list on action completion or re-added to the end of the list.

EmulatedDriver.ResponseListLooping = true

EmulatedDriver.ResponseListLooping = false

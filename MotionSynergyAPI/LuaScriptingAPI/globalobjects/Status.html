Globalobject Status

Provides access to the script Status object used to control the abort behaviour of a script and return results at the end of script execution.

These parameters can be accessed by application code once the script completes.

Parameters:

  • value The value of the out parameter to set. This can be an integer, number or string.

Abort (abortType)
Abort the currently executing script.

Two abort types are possible. A 'Controlled' abort will not exit the script until the current transaction (if in progress) completes. A 'Forced' abort will exit the script immediately, regardless of whether a transaction is in progress.

Parameters:

  • abortType string 'Controlled' or 'Forced'.

Raises:

An error is raised if the abortType is not valid.

Usage:

    -- Request a controlled abort be performed. This will not exit the script
-- until the transaction completes. A 'Forced' abort will abort the
-- script immediately.
Status.Abort('Controlled')

PreventAbort (transactionName)
Begin a 'transaction' to prevent the script aborting until the transaction completes.

While a transaction is active, any script controlled abort request (externally from application code or by calling Abort) will still set the abort flag in the script executor, but the executor will not actually abort the script until the transaction is completed.

Forced aborts will abort the script even if a transaction is in progress (see Abort).

Call EndPreventAbort to end the transaction, allowing the script to be aborted again.

Parameters:

  • transactionName string A name for the transaction. This is passed to the abort handler (see AbortHandler) if an abort is requested during the transaction.

See also:

    EndPreventAbort

Usage:

    -- Start a transaction which prevents a controlled abort from terminating
-- the script while inside the transaction. Each transaction has a name.
Status.PreventAbort('Axis Moves')

-- Move an axis to a position.
XAxis.MoveAbsolute(500)
XAxis.Wait()

-- The transaction allows the axis home to complete before the script is aborted.
XAxis.Home()
XAxis.Wait()

-- Complete the transaction. This will allows the script to abort from
-- this point on.
Status.EndPreventAbort()
EndPreventAbort ()
End the current 'transaction', allowing the script to be aborted. If a controlled abort has been requested during the transaction, the script will abort immediately once this is called.

Fields

AbortHandler
Set a function to be called when a script is aborted.

Set this property to the name of the abort handler function in the global environment (not the function itself). When an abort occurs, after the running script is aborted, the abort handler will be looked up in the global environment of the script and run.

The function to be called takes a single string parameter which is the name of the last transaction. This may be an empty string if transactions have not been used.

  • AbortHandler string

Usage:

    local log = require 'lua_logger'

-- This function will be called if the script is aborted. It allows the
-- script to perform some clean up operations.
-- If the script was aborted during a transaction, the last transaction name
-- will be passed to the script to provide some context.
function onAbort(lastTransactionName)
   log.info("Last transaction = '" .. lastTransactionName .. "'.")
   XAxis.Home()
   XAxis.Wait()
end

-- Register an abort handler. Note the abort handler is assigned the name
-- of the function in the global environment, not the function itself.
Status.AbortHandler = 'onAbort'
ShouldAbort
Returns a flag indicating if Abort has been called on this script. This allows code within a transaction to determine if abort has been called.
  • ShouldAbort boolean readonly

Usage:

    -- Start a transaction which prevents a controlled abort from terminating
-- the script while inside the transaction. Each transaction has a name.
Status.PreventAbort('Axis Moves')

-- Move an axis to a position.
XAxis.MoveAbsolute(500)
XAxis.Wait()

-- Don't home the X Axis if the script has been aborted.
if not Status.ShouldAbort then
  XAxis.Home()
  XAxis.Wait()
end

-- Complete the transaction. This will allows the script to abort from
-- this point on.
Status.EndPreventAbort()

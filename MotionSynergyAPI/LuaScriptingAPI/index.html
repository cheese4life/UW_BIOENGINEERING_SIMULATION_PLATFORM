Motion Synergy Lua API Documentation

This is the documentation for the Lua scripting interface provided by Motion Synergy.

  • Modules are modules/libraries for common services that can be imported using require().
  • Global Objects are objects that are injected into the global environment of every script execution.
  • Devices are descriptions of the interfaces for various types of devices. The actual device instances that will be present are defined in the instrument configuration, and they are injected into the global environment of every script execution.
  • Emulated Drivers are descriptions of the emulated driver interfaces of emulated devices. Emulated drivers are used to alter the behavior of emulated devices by modifying driver responses and internal states. The actual emulated driver instances that will be present are defined in the instrument configuration, and they are injected into the global environment of every script execution, if the device is configured to use its emulated driver.

See the scriptsreadme topic for a general description of how to structure lua scripts.

GlobalObjects

Status Provides access to the script Status object used to control the abort behaviour of a script and return results at the end of script execution.

Devices

AxisDevice A single axis of a motion control system (linear axis motors, rotary axis motors).
AxisDevice.MotionControllerConfiguration An interface for reading and modifying Motion Controller Configuration.
AxisDevice.UserDefinedProfile An interface for performing User Defined Profile (UDP) moves and updating the associated user defined profile data.
DigitalInputDevice A device for reading binary inputs (0 = LOW or 1 = HIGH) from one or more digital input pins.
BaseDevice Base functions and properties that all devices have (not a real device itself).

EmulatedDrivers

BaseEmulatedDriver Base function and properties that all emulated drivers have (not a real driver itself).
EmulatedAxisDriver Emulated driver of AxisDevice.
EmulatedDigitalInputDriver Emulated driver of DigitalInputDevice.

Modules

lua_alerts Provides the ability for a script to raise and clear alerts.
lua_config Provides access to the configuration system for retrieving settings from and writing settings to configuration.
lua_filesystem Provides a limited set of functions for accessing the filesystem.
lua_logger Provides access to the logging system to allow logging of diagnostic information.
lua_clock Provides access to a monotonically incrementing time source not affected by changes to the wall clock due to daylight saving transitions, NTP time source adjustments, or user changes to the time or timezone.

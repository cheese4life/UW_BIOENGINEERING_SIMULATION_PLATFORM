Module lua_alerts

Provides the ability for a script to raise and clear alerts.

Raising and clearing alerts should typically be done through the generated lua code specific to a project (e.g. CustomAlerts.lua) which provides a more convenient interface.

Functions

RaiseLowSeverityAlert (alertCode)
Raise a low severity alert.

A low severity alert is for information purposes only. The system will not take any action based on alerts with this severity.

Parameters:

  • alertCode int The code of the alert to raise

Returns:

    int A report ID which can be passed to ClearAlert if the alert needs to be cleared.

See also:

    ClearAlert

Usage:

    local alerts = require 'lua_alerts'
local reportId = alerts.RaiseLowSeverityAlert(30006)

-- Optionally clear the alert some time later.
alerts.ClearAlert(reportId)
RaiseMediumSeverityAlert (alertCode)
Raise a medium severity alert.

A medium severity alert will cause the current script to be aborted. However, the system is still in a valid state to execute further commands/scripts.

Parameters:

  • alertCode int The code of the alert to raise

Returns:

    int A report ID which can be passed to ClearAlert if the alert needs to be cleared.

See also:

    ClearAlert

Usage:

    local alerts = require 'lua_alerts'
local reportId = alerts.RaiseMediumSeverityAlert(30007)
RaiseHighSeverityAlert (alertCode)
Raise a high severity alert. This will cause the current script to be aborted. The system will be placed in an 'Error' state and a re-initialization must be performed before further commands/scripts attempted.

Parameters:

  • alertCode int The code of the alert to raise

Returns:

    int A report ID which can be passed to ClearAlert if the alert needs to be cleared.

See also:

    ClearAlert

Usage:

    local alerts = require 'lua_alerts'
local reportId = alerts.RaiseHighSeverityAlert(30008)
RaiseSafetyCriticalSeverityAlert (alertCode)
Raise a safety critical severity alert. This will cause the current script to be aborted. The state of the software system is unknown and a restart is required before attempting further commands/scripts.

Parameters:

  • alertCode int The code of the alert to raise

Returns:

    int A report ID which can be passed to ClearAlert if the alert needs to be cleared.

See also:

    ClearAlert

Usage:

    local alerts = require 'lua_alerts'
local reportId = alerts.RaiseSafetyCriticalSeverityAlert(30009)
ClearAlert (reportId)
Clear a previously raised alert.

If there is no alert with the given report ID, nothing happens.

Parameters:

  • reportId int The report ID returned when the alert was raised.

Usage:

    local alerts = require 'lua_alerts'
local reportId = alerts.RaiseLowSeverityAlert(30006)

-- Clear the alert some time later.
alerts.ClearAlert(reportId)

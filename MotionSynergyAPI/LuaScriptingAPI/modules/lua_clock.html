Module lua_clock

Provides access to a monotonically incrementing time source not affected by changes to the wall clock due to daylight saving transitions, NTP time source adjustments, or user changes to the time or timezone.

now ()
Return a microsecond timestamp representing the current time.

The timestamp is the number of microseconds from some arbitrary start time, but that start time is consistent within a script's execution. The value of a single timestamp doesn't tell you anything about the time by itself, but is instead useful for measuring the time between two events.

Returns:

    int A microsecond timestamp representing the current time.

Usage:

    local clock = require 'lua_clock'

local startTimestamp_us = clock.now()

-- Run something that takes time.

local endTimestamp_us = clock.now()

local timeTaken_us = endTimestamp_us - startTimestamp_us
now_str ()
Return the current time as a default-formatted string, in local time.

Returns:

    string The current local time in string format.

Usage:

    local log = require 'lua_logger'
local clock = require 'lua_clock'

log.info("The time on the monotonic clock is " .. clock.now_str())
sleep_ms (duration)
Pause (sleep) the script for a specified number of milliseconds.

Note that this sleep function is not precise for <10 ms delays and should not be used for timing critical operations.

Note that if the script is aborted, this function will return immediately (i.e. it will complete before the specified duration has elapsed).

Parameters:

  • duration int Duration to sleep in milliseconds.

Usage:

    local clock = require 'lua_clock'

-- Wait five seconds before continuing.
clock.sleep_ms(5000)

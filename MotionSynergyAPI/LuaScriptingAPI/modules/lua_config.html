Module lua_config

Provides access to the configuration system for retrieving settings from and writing settings to configuration.

get_boolean (iConfig, path)
Return a boolean setting from configuration.

Parameters:

  • iConfig IConfig The configuration to retrive the setting from.
  • path string The path to the setting (ie. 'section.key').

Returns:

    bool The value of the configuration setting.

Usage:

    -- Example instrument configuration file:
-- [Instrument]
-- Enable=false

local config = require 'lua_config'
-- Get a reference to the main instrument configuration.
local instrumentConfig = config.get_config()

-- Read a boolean configuration setting using a 'section.key' path.
local value = config.get_boolean(instrumentConfig, 'Instrument.Enable')
-- This returns a bool value of false.

write_local_config (iConfig)
Write all configuration setting changes to the local configuration file.

This method can be called after using the set_*() methods to persist the changes to the local configuration file associated with this configuration instance (usually [config_filename].local.cfg). If this method is not called, any changes will be lost the next time the software is restarted.

Parameters:

  • iConfig IConfig The configuration to persist.

Usage:

    -- Example instrument local configuration file before writing
-- [Heater]
-- Temperature=24.5

local config = require 'lua_config'
-- Get a reference to the main instrument configuration.
local instrumentConfig = config.get_config()

-- Update a setting
config.set_double(instrumentConfig, "Heater.Temperature", 45.2)
-- persist to local config
config.write_local_config(instrumentConfig)

-- The local configuration file is modified after write_local_config()
-- [Heater]
-- Temperature=45.2

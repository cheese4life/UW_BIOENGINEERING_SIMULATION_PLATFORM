Module lua_logger

Provides access to the logging system to allow logging of diagnostic information.

Messages logged using this module go through the IMP logger infrastructure on the channel LuaScripting.

The log.trace(), log.debug(), log.info(), log.warning(), log.error() and log.fatal() functions record the source location (i.e. filename,line number) in the script where they were invoked. They each take a second optional parameter 'functionLevel' which is used to specify the function on the stack to record. The default is functionLevel=1, which will record the source location of the call to the log.() function itself. If a script wraps a log.() function in a custom logging function, then it is more useful to log the source location of the call to the custom logging function. To do this, functionLevel can be set to the next function up in the stack (i.e. functionLevel=2).

Log an entry at 'Trace' level.

Parameters:

func (...)
Log the current function's name and provided arguments. Must be called from inside a function.

Parameters:

  • ... arguments Can be provided any number of arguments to log, including 0. These can be any type including nil.

Usage:

    local log = require 'lua_logger'

function Example(arg1, arg2)
    log.func(arg1, arg2)
end

function VariadicExample(...)
    log.func(...)
end

function NoArgumentsExample()
    log.func()
end

-- The following calls will result in one log line each.
Example(1, "test")
VariadicExample(true, false)
NoArgumentsExample()
